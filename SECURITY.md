# Security Policy

## Supported versions

Security fixes are applied to the current development version on the default
branch. The project does not currently publish a separate support schedule for
released versions.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.
Report them privately using [GitHub Security Advisories](https://github.com/researchatlas-network/researchatlas/security/advisories/new).

Include enough information for maintainers to reproduce and assess the issue:

- A description of the vulnerability and its potential impact.
- Affected components, versions, or configurations.
- Reproduction steps or a proof of concept.
- Any suggested mitigation or fix, if available.

Remove credentials, access tokens, personal data, and other sensitive
information from the report unless it is essential to reproducing the issue.

Maintainers will acknowledge reports, investigate them privately, and work
with the reporter on coordinated disclosure. Please allow reasonable time for
the issue to be assessed and corrected before making it public.
